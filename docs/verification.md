The real SwiftUI executable SHA-256 is `5aab8aed8060ce98ca0626dcf58eb515812111565756b51374a6cd47ace001f8`. Its baseline bundle has iPhone/iPad families and minimum iOS 17, but no release icons or DT metadata. The initial Linux Clang invocation also recorded SDK 17 in `LC_BUILD_VERSION` despite using SDK 26.5. A separate full xtool rebuild verified that passing the same installed SDK through Clang's Darwin `-isysroot` option produces minimum iOS 17 and SDK 26.5 without inventing a version. Incorporating that verified correction into Orchard remains part of release integration.

The supplied Xcode archive SHA-256 is `06384762f286fb4d20440f7a67ba40cdf79bedb1cbee9e5111e3030a53a6cb81`. It reports Xcode 26.6/build 17F113, SDK version 26.5 and SDK system build 23F81a. This is operator-supplied provenance, not a claim that Orchard verified Apple's archive signature. No Apple SDK is included in this repository or in distributable images.

The Arch amd64 test isolated xtool's failure to the existing QEMU 10.2.2 binfmt handler: it requires zero padding where a standard AppImage stores its `AI02` marker. Explicit QEMU extraction of the same checksum-pinned archive, followed by execution of its extracted binary, reported xtool 1.19.0. The shared emulator configuration was not changed. Managed xtool installation under this emulator remains a failed check; native amd64 installation and an Omarchy desktop session have not been proved. Go 1.24.13 also encountered a network-runtime crash under emulation; the Go 1.27.1 build completed the real downloads.

The synthetic native IPA SHA-256 is `c76b7a8820fd24f9988bc956159b0349002f9d3ed51c60a1c9edddfac0ca7633`. The private harness uses a PKCS#12 adapter only to carry its arbitrary test CA into zsign. It does not establish the production PEM identity path or Apple's trust. The receipt correctly reports Apple processing as `not_checked` and code-signature cryptographic verification as `not_performed`.

The real SwiftUI app's fixture-signed IPA SHA-256 is `8d6fc1607fb5cdaf448eca25ca9961a5d0c3296503089ce2d26bf47c6e742b8b`. It reports Mach-O SDK 26.5.0 and minimum iOS 17. Its metadata was derived from the retained real SDK records, while its profile, identity and icon artwork remain test fixtures. This exercised the distribution library through a private harness, not yet the final CLI release adapter. The same test-identity limits apply; this IPA is not offered as an installable or App Store-ready app.

Final composed CLI/GUI/container checks remain pending. Physical iPhone/iPad installation and interaction, a real Apple distribution identity, Apple upload processing, TestFlight and review submission have not been established. Unit tests, synthetic profiles and local structural inspection do not establish those results.
